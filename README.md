# AmirNet Plus

Expo app for iOS, Android, and Web.

## Run

```bash
npm install
npm start
```

Then choose:

- `i` for iOS Simulator on macOS
- `a` for Android Emulator
- `w` for Web

Direct commands:

```bash
npm run ios
npm run android
npm run web
```

## Validate

```bash
npm run lint
npm run check:deps
npm run build:web
```
